# PackIT
Demo Projet. 
The main functionality of the service is pre-ordering production components for a specific production line.
The warehouse completes components from the order and places it in a storage area with a label containing the order information  required to furthure processing.
The forklift/deliver train picks up the order at the designated time and delivers it to the line for which order was placed.
Api enables the execution of operations necessary to complete the ordering process.

Backend application built with ASP.NET Core.

## Features
- REST API
- DDD-based domain model
- Clean Architecture
- CQRS
- SQL Server / EF Core

If you provide MS Sql server connection string in appsettings -> MsSQL: ConnectionString
and run the project Db will be created, and api can be tested.
